Селекторы

Виды селекторов и их комбинаций

Виды простых селекторов
A - Селект. тэгов.
#id - Селект. индентификаторов.
.class - Селект. класса.
.class1.class2 - Мультиклассы.

------

* - Универсальный селект.
A B - Селект. потомков.
A > B - Дочерний селектор.
A + B - Соседний селект.
A ~ B - Родтсвенный селект.

[attr] - Селектор атрибутов.
[attr='value'] - Атрибут = "значение".
[attr^='value'] - Если значение атрибута начинается с указанного текста.
[attr$='value'] - Ели значение атрибута оканчивается указанным текстом.
[attr*='value'] - Определяет, что значение атрибута содержит указанный текст.
[attr~='value'] - Поиск текста при значениях атрибутов, указанных через пробел.
[attr|='value'] - Стиль применяется к элементам, у которых атрибут точно равен указанному значению или начинается с указанного значения, после которого идёт дефис.

Псевдоклассы

:hover - Определяет стиль элемента при наведении на него курсора мыши.
:nth-child() - Используется для добавления стиля к элементам на основе нумерации в дереве элементов.
:nth-last-of-type() - Используется для добавления стиля к элементам указанного типа на основе нумерации в дереве элементов.
:nth-of-type() - Используется для добавления стиля к элементам указанного типа на основе нумерации в дереве элементов.
:visited - Задаёт стиль для ссылок, уже посещённых пользователем.
:focus - Определяет стиль элемента, получившего фокус. Например, им может быть текстовое поле формы, в которое установлен курсор.

ПСЕВДОЭЛЕМЕНТЫ

::first-letter - Определяет стиль первого символа в тексте элемента, к которому добавляется.
::first-line - Задаёт стиль первой строки форматированного текста.
::before - Применяется для отображения контента до содержимого элемента, к которому он добавляется.
::after - Используется для вывода контента после содержимого элемента, к которому он добавляется.
